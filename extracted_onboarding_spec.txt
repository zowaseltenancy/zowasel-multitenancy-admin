Redesign the Zowasel Staff Onboarding page into a modern, premium, enterprise-grade onboarding experience. Use the attached reference image as the design direction, but do not copy it pixel-for-pixel. Keep the existing Zowasel sidebar and global header exactly as they are; focus the redesign on the onboarding content and workflow.

The onboarding contains 9 stages: Personal Information, Employment Details, Address Information, Next of Kin, Education, Experience, Bank Details, Documents, and Review. Do NOT use the traditional horizontal 9-step wizard across the top. Instead, create a focused two-column workflow where the main content area displays only the current step and a right-hand "Your Progress" panel communicates the overall onboarding journey.

At the top of the main content, display "Onboard New Staff" with a short supporting description such as "Let's get the basic information first. You can always edit later." Include a subtle "Save as Draft" action on the right. The main content should contain a large clean card for the current step. For Step 1, display "Personal Information" with a short description, a clear "Step 1 of 9" indicator, and a subtle horizontal progress line. Organize the form into logical sections instead of presenting fields as one long list: "Basic Information", "Contact Information", and "Personal Details". Include Profile Photo upload, First Name, Last Name, Email Address, Phone Number, Date of Birth, and Gender. Use a spacious two-column form layout on desktop and a single-column layout on mobile.

The Profile Photo area should be a clean upload component with a subtle dashed border, user/avatar placeholder, camera/upload icon, "Upload photo" text, and "JPG, PNG up to 5MB". Keep it compact and professional rather than oversized.

Create a right-hand "Your Progress" card. At the top, show a circular completion indicator with the percentage dynamically calculated from the current onboarding step. For example, Step 1 of 9 should display approximately 11%, Step 2 approximately 22%, and Step 9 as 100%. Under the percentage, show the onboarding steps as a vertical progress journey. The current step should be clearly highlighted, completed steps should use a checkmark, and future steps should remain neutral. Initially show the most relevant first few steps and provide a "View all 9 steps" control to expand the complete list. The progress panel should use dark gray for normal/inactive step text and green for the active/completed states. Do not make the progress panel visually overwhelming.

Below the main form, add a subtle contextual "Next Step" card. For Step 1 it should say "Next: Employment Details" and briefly explain what the next stage will collect, for example "We'll collect role, department, employment type and start date." This should dynamically change for each onboarding stage and should provide guidance rather than act as another navigation system.

Add a sticky bottom action bar for the onboarding workflow. On the left show "Cancel". In the center show the autosave state such as "✓ Auto-saved just now" and "Last saved: 2:35 PM". On the right show "Back" and a prominent "Continue →" button. On the first step, Back can be disabled or hidden. On the final Review step, change Continue to "Complete Onboarding". The user must be able to navigate backward and forward without losing entered information. Form data should persist between steps, and the workflow should support Save as Draft and resume later.

Use Zowasel's green visual identity as the primary color system. The main green is RGB(68, 136, 60) / #44883C. Use this green for the primary Continue button, active onboarding step, completed steps, progress indicator, success states, autosave confirmation, selected workflow elements, and important interactive states. Use RGB(85, 86, 86) / #555656 as the primary dark gray for normal typography, progress-panel text, descriptions, and secondary information. Use RGB(165, 164, 165) / #A5A4A5 sparingly for borders, dividers, inactive indicators, and disabled states. Keep the overall interface predominantly white with a very light gray page background. Do not introduce the burgundy, gold, or copper palette from previous concepts. Do not make the entire page green; green should be used strategically to establish hierarchy.

The visual language should be modern enterprise SaaS: clean, minimal, spacious, professional, accessible, and highly readable. Use consistent typography, generous whitespace, subtle borders, very light shadows, moderate corner radii, consistent input heights, and clear hierarchy. Avoid excessive gradients, heavy shadows, excessive rounded containers, unnecessary icons, decorative elements, or excessive use of green. The page should feel like a sophisticated production application rather than a generic form template.

Make all form controls production-ready with clear labels, required-field indicators, appropriate placeholders, focus states, validation states, error messages, disabled states, and accessible keyboard navigation. Use icons only where they improve usability. Make the design responsive: on desktop use the main content and right progress panel side by side; on tablet reduce the progress panel width; on mobile stack the progress information and form, replace the large vertical step list with a compact "Step X of 9" progress indicator, and keep the bottom navigation accessible.

Build the implementation using reusable, data-driven components rather than duplicating the entire page for each step. Suggested component structure: StaffOnboarding, OnboardingHeader, OnboardingProgress, ProgressCircle, StepList, OnboardingStep, StepHeader, FormSection, ProfileUpload, NextStepCard, and OnboardingActions. Define the nine onboarding stages as configuration/data and render the appropriate content based on the current step. Preserve all entered data when moving between steps.

The final UX should communicate three things immediately: "What am I doing now?", "How much have I completed?", and "What happens next?" The main form should remain the primary focus, the progress panel should provide orientation, and the bottom action bar should provide clear workflow control. The result should feel like a premium Zowasel enterprise staff onboarding experience, not a traditional multi-page form.
